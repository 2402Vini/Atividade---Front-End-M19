# 🎮 Loja Gamer - Card de Produtos com Styled Components

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um exercício prático com o objetivo de aplicar conceitos de **CSS-in-JS** utilizando **Styled Components** em uma aplicação React.

A aplicação simula uma pequena vitrine de produtos de uma loja gamer, exibindo cards com informações básicas e permitindo interação com o botão de adicionar ao carrinho.

---

## 🚀 Funcionalidades

* 📦 Exibição de produtos em formato de cards
* 🎨 Estilização com **Styled Components (CSS-in-JS)**
* 🔁 Estilização dinâmica baseada em props
* 🛒 Adição e remoção de itens no carrinho
* 🔢 Contador de itens no carrinho em tempo real
* ✨ Feedback visual no botão (cor + animação)

---

## 🧠 Conceitos aplicados

* Componentização no React
* Props e renderização dinâmica
* Gerenciamento de estado com `useState`
* **Lifting State Up** (estado centralizado no App)
* CSS-in-JS com `styled-components`
* Estilização condicional baseada em props
